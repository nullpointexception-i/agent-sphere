# AgentSphere Admin UI (agent-sphere-ui)

React 19 / UmiJS Max / Ant Design Pro. Node >= 20. Independent npm project; run commands in this directory.

## Commands

```bash
npm run dev            # :8000, MOCK=none, /api proxied to :8080
npm run build
npm run biome          # biome check --write (auto-fix)
npm run lint           # biome lint + tsc (check only)
npm run tsc            # tsc --noEmit
npm test               # jest
npm run test:coverage  # jest --coverage
```

Validation order: `npm run biome` → `npm run lint` → `npm test`.

## Routing and structure

- Routes are configuration-based: `config/routes.ts`.
- Page directories map to backend domains: `chat`, `instances`, `model-providers`, `capabilities/*`, `tasks`, `artifacts`, `admin`, `account`, `user`.
- `src/.umi/**` is generated by `max dev` / `max setup`; never edit by hand.
- Aliases: `@/*` → `src`, `@@/*` → `src/.umi`, `@root/*` → repo root.
- Service client: `src/services/agentSphere/api.ts` (hand-written, `BASE = '/api/v1'`). Biome **ignores** `src/services` and `mock`; keep that client clean manually.

## Biome

- Single quotes, space indentation, `jsxRuntime: reactClassic`.
- `noExplicitAny` and `useExhaustiveDependencies` are disabled.
- `.npmrc` must keep `legacy-peer-deps=true`.

## Magic values and constants

No raw status strings or polling numbers in pages/components. Use shared constants:

- `src/constants/status.ts` — `STATUS` (`RUN`, `WORK_ITEM`, `TASK`, `CLEANUP`, `SKILL_SYNC`, `ACTIVE`, `DISABLED`, `ENABLED`), status metadata maps, terminal/active sets.
- `src/constants/timeline.ts` — `TIMELINE_STATE`, `TODO_STATUS`, `COMPLETED_TIMELINE_STATES`.
- `src/constants/timing.ts` — `TIMING` (polling, SSE, clocks, copy reset, etc.).
- `src/constants/api.ts` / `endpoints.ts` — `API_BASE`, `API_PATHS`.
- `src/constants/permissions.ts` — `PERM`.
- `src/constants/pagination.ts` — `DEFAULT_PAGE_SIZE`, `LARGE_PAGE_SIZE`.

Rules:

- Never compare raw `'RUNNING'`/`'FAILED'`/`'ACTIVE'` in page code; use `STATUS` or domain-specific maps.
- Domain-specific states stay separate; do not create one universal status map.
- Do not import Java constants; keep values in sync manually.

## Layering and file size

- Flow: pages → components → hooks → services → constants.
- Large pages should extract:
  - pure logic → `*Model.ts`
  - presentational rows/cards → `rows/` or dedicated components
  - data/streaming logic → hooks
- Prefer small, focused components over files with many unrelated helpers.

## Testing

- Jest + jsdom; TypeScript/TSX transformed by `jest.transform.js` (esbuild).
- `jest.config.js` maps `@/`, `@@/`, `@root/`; CSS uses `test/styleStub.js`.
- `test/mocks/umijs-max.js` provides `useIntl`, `getLocale`, `history`, etc.
- Current suites cover timeline model, workspace conversation model, tool renderers, agent stream store, status/timing constants.
- Current baseline: about 69 tests. Keep `npm test` green.

## i18n

- Default locale `zh-CN`; add new copy to both `src/locales/zh-CN` and `src/locales/en-US`.
- `moment` is rewritten to `dayjs` via `moment2dayjs`.

## Hard rules

- No third-party site brand/domain in code, comments, tests, or locale files.
- Keep the `/stream` dev proxy headers (`Accept-Encoding` / `Cache-Control: no-transform`); removing them breaks SSE.
